The Craving Club - Interactive Food Gallery
An interactive, responsive web application built with vanilla HTML5, CSS3, and JavaScript. The Craving Club provides users with an intuitive visual menu gallery organized by global cuisines, complete with category filtering, dynamic image carousels, and interactive lightbox previewing.

🌟 Features
Category Filtering: Dynamically filter gallery sections by cuisine (All Cuisines, Indian, Italian, Chinese, Mexican, Japanese, and Thai).

Interactive Image Carousels: Multi-item carousel rows with custom navigation arrows (< and >) for smooth browsing.

Lightbox Modal View: Click any food image to view a full-screen preview with keyboard navigation support (Left Arrow, Right Arrow, and Escape).

Responsive Layout: Adaptive CSS media queries optimized for mobile, tablet, and desktop viewports.

Modern Dark Aesthetic: Sleek dark background complimented by rich gold and orange culinary styling.

🛠️ Tech Stack
HTML5: Semantic document structure and accessibility attributes (aria-hidden).

CSS3: Custom styling, Flexbox, Grid, smooth transforms, hover animations, and media queries.

JavaScript (Vanilla JS): Pure DOM manipulation for active tab filtering, carousel scroll calculations, lightbox state management, and keyboard event listeners.
